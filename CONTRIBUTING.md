# Правила команды

## Unity
- Версия — строго 6000.6.0f1
- Edit → Project Settings → Editor: Visible Meta Files + Force Text (уже настроено, НЕ менять).
- Рендер-пайплайн: URP (НЕ менять).
- Перед переключением ветки / мерджем / пуллом — сохранить сцены и закрыть Unity.

## Ветки и PR
- Задачи берём из Issues/Projects (assignee = владелец задачи).
- Имена веток: `feature/issue-XX-имя`, `fix/issue-XX-имя`, создаются от `beta`.
- Прямые пуши в `beta` и `main` запрещены — только через PR.
- PR: base = `beta`, описание по шаблону, `Closes #XX`, мерж кнопкой Squash and merge.
- После мержа: pull beta, удалить свою ветку, строка в чат со ссылкой на PR.

## Коммиты
- Формат: `тип: описание (#XX)`; типы: feat, fix, art, audio, level, ui, chore.
- Один коммит = одна логическая порция работы.
- `.meta` всегда вместе с файлом; удалил файл — удалил `.meta`; перенос/переименование — только вместе с `.meta`.
- Перед коммитом просмотреть список Changes и снять галочки с файлов не по задаче.

## Сцены и общие файлы
- Одна сцена = один владелец; двое не правят одну `.unity` одновременно.
- `ProjectSettings/`, `Packages/manifest.json`, префаб игрока, запекание света и билды — владелец тимлид.
- Общие префабы меняются редко и через PR с ревью лида.

## Конфликты
- `.unity`/`.prefab` руками построчно НЕ мержим: берём сторону владельца сцены, свои изменения наносим заново в Unity.
- Застрял — зови лида. Никаких `reset --hard` и force push без лида.

## Тяжёлые файлы и секреты
- Файлы >50 МБ, PSD/.blend/WAV-мастера, видео-исходники, билды — НЕ в git (облако: [https://drive.google.com/drive/folders/1BGv2HLDZ4cfSiLojmYA99mB_z3kepYdQ?usp=sharing]).
- Ключи/пароли/токены в репозиторий не попадают никогда.
